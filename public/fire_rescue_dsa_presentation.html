Project Overview & Algorithmic Foundation

Project Overview

Fire Rescue is an interactive 100-level mobile-first pipe puzzle game. Players rotate modular pipe conduits (straight, elbow, tee, cross) on a 2D matrix to construct an unbroken water channel from an exterior supply inlet to quench burning buildings and revitalize thirsty trees.

Why Breadth-First Search (BFS)?

Fluid wavefronts propagate outward in discrete waves along aligned conduit ports. BFS treats each cell as a graph vertex and each complementary port alignment as an unweighted edge, guaranteeing leak detection, fluid animation synchronization, and optimal hint calculation.

Key Architectural Differentiators

Vs. Pipe Mania:

Instead of dealing random falling pipe pieces that rely on luck, Fire Rescue provides a deterministic 2D topological graph where all pipe pieces are present from the start and must be rotated strategically.

Vs. Where's My Water?:

Instead of non-deterministic particle physics simulation that varies across hardware, Fire Rescue uses discrete graph algorithms (BFS and state trees) that execute with exact O(R × C) predictability.

Vs. Commercial Mobile Plumber Games:

Commercial games often fake water connections with hardcoded sprite animations. Fire Rescue computes real-time port compatibility bitmasks at runtime and exposes an explainable BFS search tree for hint generation.

Unique Academic Contribution: Unification of graph traversal (BFS) with bitwise port operations to achieve simultaneous fluid simulation, automated puzzle validation, and state-space hint resolution in sub-millisecond execution time.

Algorithm: Breadth-First Search (BFS) Fire Rescue | IASWE202 Data Structures and Algorithms Lab • 10

Step-by-Step BFS Execution Flow

1
Initialize Water Source
Identify inlet port at boundary. Mark source cell visited and enqueue with initial depth=0.
2
Dequeue Front Cell
Remove cell (r, c) from front of FIFO queue to simulate fluid wavefront propagation.
3
Inspect 4 Cardinal Ports
Calculate open ports of active pipe by rotating base openings clockwise by (rot × 90°).
4
Check Mutual Alignment
For each neighbor in direction D, verify target pipe has an open port in OPPOSITE direction.
5
Enqueue & Record Parent
If neighbor is unvisited and mutually open, mark visited, record predecessor, and enqueue.
6
Check Destination & Finish
If active cell connects to destination inlet, trigger success fanfare and calculate par stars.

BFS Pseudocode & Path Reconstruction Fire Rescue | IASWE202 Data Structures and Algorithms Lab • 11

BFS Flow Simulation & Hint Algorithm

function calculateWaterFlow(grid, source, destination):
    queue = new Queue()
    visited = new Matrix[R][C](false)
    parent = new Map()

    queue.enqueue(source.cell)
    visited[source.r][source.c] = true

    while not queue.isEmpty():
        curr = queue.dequeue()
        if curr == destination.cell and curr.hasPort(destination.inlet):
            return { reached: true, path: reconstruct(parent, curr) }

        for dir in [UP, RIGHT, DOWN, LEFT]:
            neighbor = curr.getNeighbor(dir)
            if neighbor and not visited[neighbor.r][neighbor.c]:
                # Mutual port-matching verification
                if curr.isOpen(dir) and neighbor.isOpen(opposite(dir)):
                    visited[neighbor.r][neighbor.c] = true
                    parent.set(neighbor, curr)
                    queue.enqueue(neighbor)

    return { reached: false, flowCells: visited }
Search Phase

The queue systematically checks connected cells level-by-level. Because each edge represents a leak-free pipe connection, water never bypasses a closed port.

Hint Generation

When no complete path exists, the solver rotates unaligned cells along the intended pipeline to identify the next rotation that advances flow toward the target.

Complexity and Why BFS Fire Rescue | IASWE202 Data Structures and Algorithms Lab • 12

Asymptotic Complexity Analysis

Time Complexity
O(V + E)
In an R × C grid, V = R × C vertices and E ≤ 4 × V edges. Each cell is visited at most once, giving O(R × C) linear time.
Space Complexity
O(R × C)
The FIFO queue and visited boolean matrix store at most one record per cell. For our largest 8×8 grid, memory footprint is < 5 KB.
Hint Solver Search
O(K · (V+E))
K candidate pipe rotations along the solution path are tested in sequence, resolving the hint in < 2 milliseconds.
Why BFS Over DFS or Dijkstra?
  • Uniform Edge Costs: Water advances 1 cell per step; BFS naturally computes the shortest route without Dijkstra's priority queue overhead.
  • Visual Fidelity: BFS matches physical outward wave expansion, eliminating erratic jumping seen with DFS.
  • Zero False Completions: BFS strictly terminates when all connected openings are exhausted or the target is attained.
